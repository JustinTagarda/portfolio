Privacy Policy for Job Tracker AI

Last updated: May 7, 2026

Overview

Job Tracker AI is a Windows desktop app for job-post analysis, career-profile management, and cover-letter generation and editing.

The app is local-first. Primary user content is stored on the user's Windows device. AI workflows run through a local model/runtime path selected by the app.

Information Stored Locally

Job Tracker AI stores data locally on the device, including:

  • job-post records and analysis results
  • uploaded or captured job-post images
  • career-profile data
  • generated and edited cover letters
  • app settings, model settings, and prompt settings
  • appearance/theme preference
  • runtime diagnostic logs

AI Processing

The app's AI workflows run through the currently selected local model/runtime path.

For supported workflows, prompt content is sent to the local runtime used by that selected model. This content can include:

  • job-post text from user-provided URLs and image OCR
  • career-profile fields used for analysis and drafting
  • cover-letter drafts during generation or modification

Current app behavior does not require an OpenAI API key or OpenAI consent flow for these workflows.

Network Activity

The app may use network access for:

  • reading user-provided job-post URLs
  • Microsoft Store licensing/trial checks
  • Microsoft Store update checks and installs
  • opening external links from Settings (for example privacy policy/support pages)

AI inference for app workflows is designed to run through the local selected-model runtime on the device.

Sharing and Disclosure

Job Tracker AI does not sell user data.

User content is stored locally except when network operations are triggered by app features such as URL capture, Microsoft Store services, or opening external links.

Security

The app uses local files and local SQLite-backed storage for persisted data. Users should avoid placing unnecessary sensitive information in free-form text fields.

User Controls

Users can:

  • select which local AI model is active
  • manage or delete local job-post and profile data
  • review and remove local app data files

Access and Deletion

Users can access, edit, and delete data inside the app where supported.

Uninstalling the app may not automatically remove all local data files or model/runtime artifacts. Users who want full cleanup should remove app data directories and related local model/runtime files manually.

Changes to This Privacy Policy

This policy may be updated over time. The latest version should be published at the app's privacy policy URL.
