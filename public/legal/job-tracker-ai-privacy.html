Privacy Policy for Job Tracker AI

Last updated: April 12, 2026

Overview

Job Tracker AI is a Windows desktop application for managing job applications, analyzing job posts, and drafting or editing cover letters.

This product is local-first. Most user data is stored on the user's Windows device. AI-assisted features are optional and require the user to provide their own OpenAI API key.

Information Stored Locally

Job Tracker AI can store the following information on the local device:

  • job-post records, including saved analysis results
  • job-post screenshots and extracted text artifacts
  • career-profile and applicant-profile data entered by the user
  • saved cover-letter drafts and edits
  • application settings, model settings, and prompt settings
  • runtime diagnostic logs

OpenAI API Key Handling

If the user enables AI-assisted features, the user-provided OpenAI API key is stored in Windows Credential Manager under the JobTracker application credential target. The API key is not stored in the app's JSON or SQLite files.

AI-Assisted Features and Data Transfer

AI-assisted features are optional and are used only when all of the following are true:

  • the user has stored an OpenAI API key
  • the user has turned on workflow AI-assist
  • the user has accepted the in-app OpenAI data-transfer consent

When AI-assisted features are enabled, Job Tracker AI may send relevant content to OpenAI, including:

  • job-post text captured from screenshots or URLs
  • career-profile and applicant-profile data needed for analysis or drafting
  • existing cover-letter content when the user asks the app to generate or edit a cover letter

The app uses that content to perform job-post analysis, policy checks, legitimacy and fit analysis, and cover-letter generation or modification.

Turning AI mode off in the app stops future OpenAI transmission for those workflows.

Sharing and Disclosure

Job Tracker AI does not sell user data.

When AI-assisted features are enabled, relevant workflow content is transmitted to OpenAI as the third-party AI service provider for the requested feature. Outside of that workflow, the app is designed to keep user data on the local device.

Security

The app stores local records in application-managed files and databases on Windows. The app also uses Windows Credential Manager for the OpenAI API key.

Runtime diagnostics are retained locally to help with troubleshooting. Users should avoid storing unnecessary sensitive information in free-form fields and should review any data they choose to send through AI-assisted workflows.

No method of local storage, transmission, or electronic processing can be guaranteed to be completely secure.

User Controls

Users can control data use in the following ways:

  • keep the app in local mode without storing an OpenAI API key
  • remove the OpenAI API key from Windows Credential Manager
  • turn workflow AI-assist off in Settings
  • manage or delete local job-post records and profile data

Access and Deletion

Users can access, review, edit, or delete job-post records, profile data, and other locally stored content through the app where supported. Uninstalling the app may not automatically remove all locally stored files or the saved OpenAI API key. Users who want fuller local cleanup may need to delete locally stored app data from their Windows device and remove the OpenAI API key from Windows Credential Manager.

Changes to This Privacy Policy
